# AutoCare — тестовые сборки

Здесь лежат готовые APK для тестирования.

## Как установить

1. Открой [последний релиз](https://github.com/iLocative/AutoCare-releases/releases/latest) и скачай файл `AutoCare-….apk`.
2. Открой скачанный файл. Android попросит разрешить установку из этого источника — разреши.
3. Нужен Android 11 или новее.

Дальше приложение обновляется само: при запуске оно предложит поставить новую версию.
Все версии подписаны одним ключом — обновление ставится поверх, данные сохраняются.
